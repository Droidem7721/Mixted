# Red Neuronal Multicapa

Implementación de una red neuronal con múltiples capas densas.

## Características
- Capas densas (fully connected)
- Funciones de activación: ReLU, Sigmoid, Linear
- Algoritmo de backpropagation
- Optimización basada en gradientes

## Uso
```bash
python nn_multicapa.py
```

## Ejemplo: XOR Problem
La red puede aprender a resolver el problema XOR, que requiere al menos una capa oculta.
