# Clasificador MNIST

Clasificador simple para el dataset MNIST de dígitos escritos a mano.

## Características
- Regresión logística multinomial
- Normalización de características
- Cálculo de precisión

## Requisitos
```bash
pip install numpy scikit-learn
```

## Uso
```bash
python mnist_classifier.py
```

## Dataset
Utiliza el dataset de dígitos MNIST reducido de scikit-learn (8x8 píxeles).
