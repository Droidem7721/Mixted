# Proyectos de Redes Neuronales en Python

Colección de proyectos simples educativos sobre redes neuronales implementados desde cero en Python.

## 📁 Proyectos Incluidos

### 1. **Perceptrón Simple** (`01_Perceptron_Simple/`)
- Implementación básica de un perceptrón
- Función de activación: paso unitario
- Ejemplo: puerta lógica AND

### 2. **Red Neuronal Multicapa** (`02_Red_Neuronal_Multicapa/`)
- Red con múltiples capas densas
- Funciones de activación: ReLU, Sigmoid, Linear
- Backpropagation
- Ejemplo: problema XOR

### 3. **Clasificador MNIST** (`03_Clasificador_MNIST/`)
- Clasificación de dígitos escritos a mano
- Regresión logística multinomial
- Normalización de características
- Dataset: MNIST reducido (8x8)

### 4. **Autoencoder** (`04_Autoencoder/`)
- Red para aprender representaciones comprimidas
- Encoder y decoder
- Espacio latente
- Aplicaciones: compresión, anomalías

## 🚀 Requisitos

```bash
pip install numpy scikit-learn matplotlib
```

## 📊 Cómo Usar

Cada proyecto tiene su propio directorio. Para ejecutar un proyecto:

```bash
cd 01_Perceptron_Simple
python perceptron.py
```

## 📚 Conceptos Cubiertos

- ✅ Forward propagation
- ✅ Backward propagation (backpropagation)
- ✅ Funciones de activación
- ✅ Optimización basada en gradientes
- ✅ Regularización básica
- ✅ Evaluación de modelos

## 🎓 Nivel

Estos proyectos son **educativos** y están diseñados para aprender los fundamentos de las redes neuronales. Para aplicaciones en producción, se recomienda usar frameworks como TensorFlow o PyTorch.

## 📝 Notas

- Todos los proyectos se implementaron **desde cero** sin usar frameworks de deep learning
- El código está comentado para facilitar el aprendizaje
- Cada proyecto incluye un ejemplo práctico
