# Árbol de Decisión y AdaBoost

Implementación de Árbol de Decisión y Ensemble learning con AdaBoost.

## Características

### Árbol de Decisión
- **Criterio de splitting**: Ganancia de información
- **Entropía de Shannon**: Medida de impureza
- **Profundidad limitada**: Previene overfitting
- **Interpretabilidad**: Decisiones explicables

### AdaBoost
- **Ensemble learning**: Combina múltiples árboles débiles
- **Ponderación adaptativa**: Enfatiza muestras difíciles
- **Voto ponderado**: Cada árbol tiene peso diferente
- **Mejora iterativa**: Reduce error progresivamente

## Conceptos
- Entropía y ganancia de información
- Muestreo ponderado (weighted sampling)
- Boosting adaptativo
- Clasificadores débiles vs fuertes

## Uso
```bash
python arbol_decision_boosting.py
```

## Aplicaciones
- Clasificación con datos tabulares
- Problemas interpretables
- Datasets pequeños a medianos
