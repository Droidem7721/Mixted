## 🚀 Quick Start

### Instalación
```bash
git clone https://github.com/Droidem7721/Mixted.git
cd Mixted
pip install numpy scikit-learn matplotlib scipy
```

### Ejecutar Básico
```bash
cd 01_Perceptron_Simple
python perceptron.py
```

### Ejecutar Intermedio
```bash
cd 05_Intermedio_Red_Avanzada
python red_avanzada.py
```

### Ejecutar Avanzado
```bash
cd 06_Proyecto_IA_Real
python ejemplos.py
# Elige opción de ejemplo
```

### Ejecutar Estado del Arte
```bash
cd 07_AVANZADO_Transformers
python transformers_avanzado.py
```
