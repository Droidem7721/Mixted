# Perceptrón Simple

Implementación de un perceptrón básico para clasificación binaria.

## Características
- Función de activación: paso unitario
- Aprendizaje por regla delta
- Entrenamiento iterativo

## Uso
```bash
python perceptron.py
```

## Ejemplo: AND Gate
El perceptrón puede aprender a clasificar la operación lógica AND.
