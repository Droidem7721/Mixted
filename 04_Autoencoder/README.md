# Autoencoder

Red neuronal que aprende a codificar y decodificar datos en un espacio latente de menor dimensionalidad.

## Características
- Encoder y decoder
- Espacio latente comprimido
- Función de activación ReLU en encoder
- Función de activación Sigmoid en decoder
- Pérdida MSE

## Uso
```bash
python autoencoder.py
```

## Aplicaciones
- Compresión de datos
- Reducción de dimensionalidad
- Detección de anomalías
- Generación de datos
